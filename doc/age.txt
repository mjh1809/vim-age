1. INTRODUCTION						*age-intro*

Files ending in ".age" are decrypted when opened and encrypted again when
written, using age (https://age-encryption.org) with an age-plugin-yubikey
identity. The plaintext never touches the disk.

==============================================================================
2. REQUIREMENTS						*age-requirements*

- Vim 8.0 or later
- age, age-plugin-yubikey and python3 in $PATH. Python hands the PIN to age,
  which otherwise insists on reading it from the terminal.

==============================================================================
3. INSTALLATION						*age-install*

With Vim's built-in packages: >
	mkdir -p ~/.vim/pack/age/start
	cp -r vim-age ~/.vim/pack/age/start/
	vim -c 'helptags ~/.vim/pack/age/start/vim-age/doc' -c q
<
Or with any plugin manager, pointing it at the vim-age directory.

==============================================================================
4. USAGE						*age-usage*

:edit file.age		Asks for the YubiKey PIN, then for a touch, and shows
			the plaintext. Each open asks for the PIN again: every
			age run is a new YubiKey session. The PIN is not
			stored. A wrong PIN or no touch within
			|g:age_timeout| seconds aborts without retrying.
			On failure the buffer is made 'nomodifiable', so an
			empty buffer cannot be written over the file.

:write			Encrypts to every recipient in |g:age_recipients_file|.
			No PIN is needed. The file is replaced only after
			encryption succeeded.

:{range}write f.age	Encrypts just those lines.

:read file.age		Inserts the decrypted text below the cursor.

:write >> file.age	Refused: appending would corrupt the file.

The filetype is detected from the inner name, e.g. notes.md.age is markdown.

==============================================================================
5. OPTIONS						*age-options*

Set these in your vimrc; defaults shown. The defaults of |g:age_identity| and
|g:age_recipients_file| are placeholders: point them at your own files.

						*g:age_identity*
	let g:age_identity = '~/.age/yubikey-identity.txt'
The age-plugin-yubikey identity file used to decrypt. It is not secret.
Create it with: >
	age-plugin-yubikey --identity > ~/.age/yubikey-identity.txt
<

						*g:age_recipients_file*
	let g:age_recipients_file = '~/.age/recipients.txt'
The recipients file used for every write. Include a backup recipient: a
YubiKey's private key cannot be exported.

						*g:age_timeout*
	let g:age_timeout = 60
Seconds to wait for the PIN to be accepted and the YubiKey touched.

						*g:age_python*
	let g:age_python = 'python3'
The Python interpreter that runs the PIN helper.

						*g:age_disable_viminfo*
	let g:age_disable_viminfo = 1
When 1, 'viminfo' is cleared for the rest of the session once an age file
is opened, so registers and history holding plaintext are not saved to
~/.viminfo. Note this also stops saving history for other files.

==============================================================================
6. SECURITY NOTES					*age-security*

- Swap, undo and backup files are disabled for age buffers.
- 'shelltemp' is turned off around each age call, so plaintext goes through
  pipes, not temp files; your own setting is restored afterwards.
- The plaintext is in Vim's memory while you edit, and could reach the disk
  if the system swaps or Vim crashes and dumps core.
- Yanking to the "+ or "* registers puts plaintext on the system clipboard.
