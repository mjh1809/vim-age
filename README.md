# vim-age

Edit [age](https://age-encryption.org)-encrypted files in Vim, decrypting with
a YubiKey through [age-plugin-yubikey](https://github.com/str4d/age-plugin-yubikey).

Open a `.age` file and Vim asks for your YubiKey PIN, waits for a touch, and
shows the plaintext. Write it and it is encrypted again to a list of
recipients. The plaintext is never written to disk.

## Requirements

- Vim 8.0 or later
- [age](https://github.com/FiloSottile/age)
- [age-plugin-yubikey](https://github.com/str4d/age-plugin-yubikey) and a
  YubiKey with an age identity
- Python 3 (used to hand the PIN to age, which otherwise reads it only from a
  terminal)

## Installation

With Vim's built-in packages:

```sh
mkdir -p ~/.vim/pack/age/start
git clone <repository-url> ~/.vim/pack/age/start/vim-age
vim -c 'helptags ~/.vim/pack/age/start/vim-age/doc' -c q
```

Or add the repository with any plugin manager.

## Setup

1. Create an age identity on the YubiKey, if you don't have one, and save its
   identity file:

   ```sh
   age-plugin-yubikey --generate
   age-plugin-yubikey --identity > ~/.age/yubikey-identity.txt
   ```

2. Create a recipients file listing everyone a file should be encrypted to,
   one recipient per line (`#` starts a comment). Include a backup recipient:
   a YubiKey's private key cannot be exported, so if the YubiKey is lost, files
   encrypted only to it are unrecoverable.

   ```
   # YubiKey
   age1yubikey1...
   # offline backup key
   age1...
   ```

3. Point the plugin at both files in your vimrc. The defaults shown are
   placeholders:

   ```vim
   let g:age_identity = '~/.age/yubikey-identity.txt'
   let g:age_recipients_file = '~/.age/recipients.txt'
   ```

## Usage

| Command | Effect |
| --- | --- |
| `:edit file.age` | Asks for the PIN and a touch, then shows the plaintext |
| `:write` | Encrypts to every recipient in the recipients file (no PIN needed) |
| `:{range}write file.age` | Encrypts just those lines |
| `:read file.age` | Inserts the decrypted text below the cursor |
| `:write >> file.age` | Refused: appending would corrupt the file |

- The PIN is asked every time a file is opened, because each age run is a new
  YubiKey session. It is not stored.
- A wrong PIN, or no touch within `g:age_timeout` seconds, aborts without
  retrying, so a typo can't use up more than one of the YubiKey's PIN
  attempts.
- If opening fails, the buffer is made read-only, so an empty buffer can't be
  written over the encrypted file.
- A file is replaced only after encryption succeeds.
- The filetype comes from the inner name: `notes.md.age` is markdown.

## Options

| Option | Default | Meaning |
| --- | --- | --- |
| `g:age_identity` | `~/.age/yubikey-identity.txt` | age-plugin-yubikey identity file (not secret) |
| `g:age_recipients_file` | `~/.age/recipients.txt` | Recipients used for every write |
| `g:age_timeout` | `60` | Seconds to wait for the PIN and touch |
| `g:age_python` | `python3` | Python interpreter for the PIN helper |
| `g:age_disable_viminfo` | `1` | Clear `'viminfo'` once an age file is opened |

See `:help age` for details.

## Security

- Swap, undo and backup files are disabled for age buffers.
- `'shelltemp'` is turned off around each age call so the plaintext goes
  through pipes, not temp files. Your own setting is restored afterwards.
- With `g:age_disable_viminfo` (the default), `'viminfo'` is cleared for the
  rest of the session, so registers and history holding plaintext aren't saved.
  This also stops saving history for other files in that session.
- The plaintext is in Vim's memory while you edit, and can still reach the
  disk if the system swaps or Vim dumps core.
- Yanking to the `"+` or `"*` registers puts plaintext on the system
  clipboard.

## How it works

age asks for the YubiKey PIN only on a terminal. The plugin asks for the PIN
with `inputsecret()`, then runs `python/age_pin.py`, which starts
`age -d` on a private pseudo-terminal, answers the PIN prompt, and returns
the plaintext to Vim through a pipe.
